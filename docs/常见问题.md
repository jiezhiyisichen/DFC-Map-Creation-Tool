## 安装与加载

**Q：装好了，但指令用不了 / 特效没反应？**

按顺序排查：

1. **权限**：特效指令的权限等级是 **2**，需要 OP 或命令方块执行。
2. **双端安装**：指令在**服务端**注册，画面在**客户端**渲染。
   - 只装服务端 → 指令能注册，但玩家看不到任何特效；
   - 只装客户端 → 连指令都没有。
3. **单人游戏**：集成服务器也会注册指令，客户端装了就能用。

**Q：模组加载成功了吗？**

看日志。加载成功会打印一个 `jiezhi` 的 3D ASCII 大字 LOGO 和 `JiezhiMod v3.4 is loading.`。

**Q：创造物品栏里找不到「jiezhimod物品」页？**

该页是本模组自建的专属页，位于创造物品栏最右（可能需要横向滚动）。完全没有该页说明模组没加载，先看日志。

## 构建与崩溃

**Q：模组启动就崩溃，报 `integrity check failed`？**

jar 内置**双重完整性校验**。这说明文件被改动过——反编译、二次打包、解压修改都会触发。请从**官方发布页**重新下载完整 jar。

如果你是从源码自己构建的：确认**三步构建全部重跑过**，并且跑完之后没有再改源码或资源。

**Q：`VerifyError: Expecting a stackmap frame at branch target`？**

构建第 3 步（ASM 补帧 + 封印注入）没跑，或 ProGuard 配置里被加了 `-dontpreverify`。详见 [构建指南](构建指南.md)。

## DFC 显示器

**Q：屏幕显示 `NO LINK` / 一堆 `--`？**

两条原因：

1. **没装 HBM 的核科技（NTM-CE）** —— 屏幕是纯反射读取，没有对应模组就是没数据；
2. **屏幕还没绑定数据源** —— 拿 DFC 遥控器右键 DFC 核心或 DFC 稳定器记录，再右键显示器完成绑定。

> 屏幕对 HBM 是**纯反射的软依赖**，没装时**不会崩**，只会显示 `NO LINK`。

**Q：整屏是「离线」页？**

反应堆温度**没到 100°C**。冷堆的 0 只是"没开机"，不是真实读数——所以整屏改画离线页。等升温到 100°C 以上就会切回主界面。

**Q：屏幕一直是黑的？**

- 还没开机：**右键**开关机（自定义显示屏是在 GUI 里点"开机"）；
- 刚重新加载存档：屏幕会自动重启一遍开机流程，等两三秒；
- 三块屏挨着放不冲突（选页判据是**控制器方块本身**）。

**Q：遥控器蹲下右键设备没反应？**

现在会**明确告诉你原因**，两种情况分开说：

- `no readable device within 3 blocks` —— 附近真的没有可读设备；
- `unsupported block: <类名>` —— 这个方块有数据但模组读不了。

**点不准**也没关系：大桶模型会放大到好几格、9×9 叶片的准心也常落在空处，遥控器会自动**解多方块代理链**并**就近扫描 3 格**，记下的是**设备自己的坐标**。

**Q：自定义屏最多 8 条，能多接几台吗？**

不能，版面就那么大。可以并排放第二块屏，各接各的。

**Q：某一项数据一直是 `--`？**

可能是 HBM 版本差异导致反射取不到。欢迎提 issue，并附上你装的 NTM-CE 版本号。

**Q：熔毁报错 301 是什么？**

**坍缩度一离开 0**（也就是爆炸倒计时启动 = 核心开始炸）就整屏改画「错误 301 · 与核心失去连接」，停留 4 秒后**自动重启屏幕**。这是刻意的演出，不是 bug。

## 指令与特效

**Q：命令方块提示"无权使用该指令"？**

指令权限等级是 2，命令方块（等级 2）本来就能执行。若仍报错，检查是否被其他权限插件覆盖，或改用 `/execute` 触发。

**Q：`/white 40` 报"数字过大"？**

不会。单参数按 ticks 解析，`alpha` 默认 1.0；只有给定第二个参数时才按 0~1 校验。

**Q：白屏时画面没模糊？**

余像阶段（主闪结束后）**故意关闭模糊**以模拟视力恢复；另外若内置 shader 被其他模组占用或资源缺失，会静默降级为纯白屏（只白不模糊），不会崩。

**Q：倒计时归零后 `00:00` 一直挂着？**

刻意保留的，方便 `/countdown_test 名称 0 0` 检测"已结束"。用 `/countdown_remove 名称` 清掉即可。

> 倒计时存在**服务端**：玩家退出再进不会清空；只有重启服务器 / 重载世界才会全部清空。

**Q：`/countdown_test` 读数和屏幕显示差 1 秒？**

口径不同：`/countdown_test` 读的是服务端整秒剩余（`剩余 tick ÷ 20` **向下取整**），而屏幕上的样式 4/5/6 显示的是**向上取整**的十分位。做精确判定（"正好 3 秒时触发"）请**以检测值为准**，或把区间放宽一格。

**Q：多人服务器上特效没反应？**

客户端必须装本模组。只装服务端能注册指令，但看不到画面。

**Q：`/notice` 发了但没人收到？**

通知只对**当前在线**玩家推送，离线玩家不补发。另外服务端必须装本模组（`/notice` 是服务端指令，靠网络包下发）。

## 物品

**Q：线圈放进背包了，怎么没生效？**

三件线圈都必须**拿在手上**（主手或副手均可）才生效；放背包 / 快捷栏未选中都不行。另外服务端也要装本模组。

**Q：治愈线圈的"4 点"到底是多少？**

血条上的 **2 颗心**（生命上限 20 点 = 10 颗心）。想要 4 颗心 = 8 点/秒，把 `HealingCoilEffect.HEAL_PER_SECOND` 改成 `8.0F` 重新构建。

**Q：线圈和药水能叠加吗？**

能。三件线圈都**不用药水效果实现**（直接改物理量 / 生命值），所以不占用效果栏，喝了药水会在线圈基础上再进一步。

**Q：喷气背包怎么用？**

**喷气背包**穿在**胸甲槽**，把**喷气开关**拿在手上，**按住右键**起飞、**松开右键**立刻失去动力。准星下方有热量条（绿→黄→橙），满了会过热，必须冷却到 30% 以下才能再飞。单次满燃料最多连续 **18 秒**。

## 聊天栏与通知

**Q：装了别的聊天 / UI 模组，聊天栏动效失效了？**

接管方式是客户端初始化时把 `GuiIngame` 里的聊天实例换成本模组的子类；如果另一个模组在之后又换了一份，以最后换的为准。反射替换失败时本模组会保留原版聊天（**不会崩**），只是没有动效。

**Q：通知历史是哪个键？**

默认 **`P`**。可在 `Options → Controls` 的 `jiezhimod` 分类里改。

> 为什么用 `P` 这种冷门键：早期用裸 `N`，被整合包其他 mod 占用了；改成 `Ctrl/Shift + N` 之后**组合键同样被其他 mod 拦截**。最终方案是换成一个游戏内几乎没人用的功能键并裸键触发。
> 唯一守住的底线是：**任何界面打开时都不触发**——否则在聊天框打字母 p 时会把聊天框顶掉，输入到一半的字和历史全丢。

**Q：通知停留多久？**

8 秒后向右侧滑出淡出。同屏最多叠 6 条，历史保留 300 条。
